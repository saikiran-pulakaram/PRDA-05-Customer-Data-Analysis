# 📊 Customer Data Analysis

### PRDA-05 | Data Analytics Project

---

## 📌 Project Overview

Customer Data Analysis is a data analytics project focused on understanding customer shopping behavior, purchasing patterns, sales performance, revenue generation, and payment preferences.

This project uses SQL for data cleaning and analysis and Microsoft Power BI for developing interactive dashboards and generating meaningful business insights.

## 🎯 Project Objectives

* Analyze customer shopping patterns.
* Understand gender-wise purchasing behavior.
* Identify age-group-wise shopping trends.
* Analyze product category performance.
* Evaluate revenue and quantity distribution.
* Examine payment method preferences.
* Compare shopping performance across different malls.
