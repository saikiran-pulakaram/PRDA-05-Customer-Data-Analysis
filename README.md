# 📊 Customer Data Analysis Project

### 🔍 An End-to-End Data Analytics Project Using SQL & Power BI

---

## 📌 Project Overview

This project focuses on analyzing customer shopping behavior using **MySQL and Microsoft Power BI**. The objective is to explore customer purchasing patterns, identify sales and revenue trends, understand customer preferences, and generate meaningful business insights from transactional data.

The project follows an end-to-end data analysis approach, covering data exploration, SQL-based analysis, business problem-solving, and interactive dashboard development.

---

## 🎯 Business Problem Statement

Understanding customer purchasing behavior is essential for businesses to improve decision-making, identify customer preferences, and optimize sales strategies.

This project analyzes customer transaction data to answer important business questions related to:

- 👥 Customer demographics and gender distribution.
- 🛍️ Product categories and purchasing patterns.
- 📈 Sales performance and revenue generation.
- 🎂 Customer age groups and shopping behavior.
- 💳 Payment methods and customer preferences.
- 🏬 Shopping mall performance and customer transactions.
